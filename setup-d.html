The lane file — install it from the projects repo

install-lanes.sh from card B places the lane files for togo-emr and togo-facility-tools. It deliberately does not place this one: the Command lane file lives with the private repos, because only granted users should read it.

Once projects/ is cloned, run its installer:

bash ~/claude/command/projects/lane-claude/install-command-lane.sh
bash ~/claude/command/projects/lane-claude/install-command-lane.sh

It writes ~/claude/command/CLAUDE.md. Edit the copy in the repo (lane-claude/command.CLAUDE.md), commit, then re-run the installer — never hand-edit the installed file, or yours is the only machine that has the change.

Phase 3 · Lane discipline — the part that matters
🧭

Keep the lanes apart

  • ~/claude/command/ is its own lane with its own rules; the global router in ~/.claude/CLAUDE.md also applies.
  • Never write SEGE content into an EMR repo, and never write EMR code under the Command lane. No SEGE issues in emr-beta.
  • Private staffing data stays in sege-staffing. It does not get copied into the dashboard repo, an issue, a PR, or a chat.
  • Cross-lane questions are fine — “how does the SEGE tracker label things versus the portal tracker?” Cross-lane files are not.
✅
If Command lane work is all you do, open your sessions in ~/claude/command/ — not ~/claude, which is a container and loads no lane rules at all.

Four rules for the Command lane

The first one is about real people’s data. The rest keep the two products from bleeding into each other.

🔒 The PII grant is separate on purpose

sege-staffing holds real onboarding data about real people. It is a second, deliberate grant — treat being given it as a responsibility, not a convenience.

🚫 No empty lane folders

Create ~/claude/command/ only after access lands. An empty lane that loads rules is a trap for your future self.

🧭 One lane per session

Open the session in the lane the work belongs to. A session in ~/claude loads nothing and will happily write to the wrong tree.

📄 Install the lane file, don't hand-write it

Run lane-claude/install-command-lane.sh from the projects repo. Edit the repo copy and re-run it; never hand-edit ~/claude/command/CLAUDE.md.
