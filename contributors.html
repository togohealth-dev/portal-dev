Method & honesty notes

Hours formula: 1.5h fixed (branch setup, localhost run-through, PR write-up, tracker move) + (additions + 0.35×deletions) ÷ 55 lines/hr + 0.25h per changed file + 0.2h per commit beyond the second.

Attribution is by PR author. Commit authorship could not be used — 77 of 110 commits in this dataset are recorded as invalid-email-address (an unconfigured git identity), so they map to no GitHub account.

Six projects are floors, not point estimates. Where a linked PR contains only migrations or a very small diff relative to the project’s stated scope, the real build time is higher than shown.

Nineteen completed projects are missing entirely — the early batch (#59–#72 and others) has no linked PR, so there is no code to measure. This page covers the 22 that do.
